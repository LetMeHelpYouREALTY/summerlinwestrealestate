# SEO Code Review Rules - Summerlin West Real Estate

## SEO Requirements

### Page Structure
- Use proper HTML semantic elements
- Implement proper heading hierarchy (H1, H2, H3)
- Include proper meta tags
- Use descriptive page titles

### Content Optimization
- Include relevant keywords naturally
- Use proper internal linking
- Implement breadcrumb navigation
- Provide unique, valuable content

## Technical SEO

### Performance
- Optimize for Core Web Vitals
- Implement proper image optimization
- Use efficient loading strategies
- Minimize bundle size

### Mobile Optimization
- Ensure mobile-first responsive design
- Optimize for mobile performance
- Use proper viewport settings
- Test on various devices

## Real Estate SEO

### Property Listings
- Include property-specific keywords
- Use descriptive property titles
- Provide detailed property descriptions
- Include location-based keywords

### Local SEO
- Optimize for local search terms
- Include location information
- Use proper schema markup
- Implement local business listings

## Schema Markup

### Real Estate Schema
- Implement RealEstateAgent schema
- Use LocalBusiness schema
- Include Property schema for listings
- Add Organization schema

### Structured Data
- Use JSON-LD format
- Validate schema markup
- Include all required properties
- Test with Google's tools

## Image SEO

### Image Optimization
- Use descriptive file names
- Include proper alt text
- Optimize image sizes
- Use appropriate formats (WebP, AVIF)

### Property Images
- Include property-specific alt text
- Use high-quality images
- Implement proper image loading
- Provide image captions when needed

## Content Quality

### Unique Content
- Avoid duplicate content
- Provide original property descriptions
- Include local market insights
- Update content regularly

### User Experience
- Ensure fast loading times
- Implement proper navigation
- Use clear call-to-actions
- Provide helpful information

## AI Hallucination Detection

### SEO-Specific Hallucinations
- **Non-existent Meta Tags**: Flag meta tags that don't exist in HTML specification
- **Fake Schema Markup**: Detect schema properties that aren't valid
- **Invalid SEO Methods**: Identify SEO optimization methods that don't exist
- **Fake Performance Claims**: Flag performance improvements that aren't real
- **Invented SEO Tools**: Detect SEO tools or methods that don't exist

### Verification Requirements
- **HTML Specification**: Verify meta tags against HTML specification
- **Schema.org**: Check schema markup against Schema.org documentation
- **SEO Best Practices**: Validate against established SEO guidelines
- **Performance Metrics**: Verify performance claims with actual testing
- **SEO Tools**: Check against actual SEO tools and methods

## Common SEO Issues to Flag

### Technical Issues
- Missing meta tags
- Poor page structure
- Slow loading times
- Mobile usability issues
- **AI Hallucinations**: Non-existent meta tags or SEO methods

### Content Issues
- Duplicate content
- Missing alt text
- Poor keyword usage
- Incomplete information
- **Invalid SEO Claims**: SEO improvements that aren't real

### Real Estate Specific
- Missing property details
- Incomplete contact information
- Poor local SEO optimization
- Missing schema markup
- **Fake Real Estate SEO**: Methods that don't exist for real estate SEO

### Performance Issues
- Large image files
- Unoptimized code
- Slow API responses
- Poor caching strategies
- **Invalid Performance Claims**: Performance improvements that aren't real
